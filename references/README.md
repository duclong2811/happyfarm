# Reference Repositories Policy

This folder contains notes or links to external projects used only for study.

Rules:
- Never import production code from this directory.
- Verify an explicit compatible license before copying any source.
- If license is unclear or incompatible, study behavior/architecture and reimplement cleanly.
- Do not copy proprietary assets, UI, game data, maps, progression tables, names, or copyrighted content.
- Record source URL, license, inspected subsystem, and what concept was reused/reimplemented.
